研究框架与指标口径 方法论

研究问题
RQ1 平台联动：角色 B 站官方视频的播放量与收藏数是否同步？相关性强度如何？
RQ2 结构差异：地区、元素、武器、星级分组下的指标分布有何差异？
RQ3 分布形态：曲目评论数是否呈长尾分布？哪些曲目属于评论高异常值？
RQ4 互动规模：同一批有效角色的官方视频中，播放、收藏、弹幕总量的相对规模分别是多少？
指标定义与统计方法
角色级指标：B站「原神」官方账号角色视频的播放量（万）、收藏数（千）、弹幕数（千）。
曲目级指标：网易云单曲评论总数（条）、网易云红心数（客户端 UI 粗粒度标签：<1000 为精确值，999+/1w+/10w+/100w+ 为档位，统计取下限不估算精确值）、B站「原神+曲名」最相关视频播放量（次）。
统计方法：描述统计（样本量 n、均值、中位数、四分位距 IQR、变异系数 CV）、Pearson 相关、分组比较、相对全角色最大值指数与对数归一化、Tukey 高异常值判定。
样本：角色目录共 122 名；角色级联合分析使用播放、收藏、弹幕三项均完整的 105 名有效角色，缺失者不按 0 计入；1753 首具备至少一项真实指标的官方曲目（去重后）。

地区角色视频指标相对全角色最大值指数 地区均值 ÷ 全角色最大值

仅纳入播放、收藏、弹幕三项均有效的角色，全局有效 n = 105，各地区另行标注有效 n，缺失者不按 0 计入。每个单元格 = 该地区有效角色的指标均值 ÷ 全部有效角色中该指标的单角色最大值 × 100%。这不是 min-max 归一化，也不减去最小值；百分比只表示地区均值相对全角色最大值的位置，不是转化率或绝对指标。

地区角色视频播放量均值与中位数 无序分类比较

地区是无序类别，采用分立条形比较均值与中位数，不连接为趋势线。每组仅纳入有播放量实测值的角色并标注有效 n；悬停可查看均值、中位数、最高值与最低值，点击仍进入对应地区。均值与中位数均使用同一组有效角色，缺失值不参与计算。

同一批角色视频的播放、收藏与弹幕规模 相对规模

对播放、收藏、弹幕三项均完整的有效角色分别汇总对应官方视频指标，以播放总量为 100% 绘制三条互不相连的条形。百分比仅是指标总量之比，不表示用户行为顺序、阶段转化或留存；曲目级网易云红心与评论不进入此图。

星级角色视频播放量分布对比 分布分析

5 星与 4 星角色官方视频播放量的分布形态对比。方法：按播放量区间等宽分箱（12 箱）绘制背靠背直方图；虚线标注各组中位数，用于比较集中趋势与离散程度。中位数对极端值不敏感，比均值更适合描述右偏分布；无官方视频的角色不参与统计。

元素分组热度对比 分类分析

按七元素分组比较角色数量、人均播放与人均收藏。方法：组内求均值（仅含有官方视频实测数据的角色）并给出角色数与占比；元素间差异同时受角色数量与单个角色热度影响，因此需结合「数量占比」与「人均热度」两条线索解读，避免把样本量差异误判为热度差异。

武器类型分组热度对比 分类分析

按五类武器分组比较角色数量、人均播放与人均收藏。方法：组内描述统计（角色数、有效样本 n、均值、中位数、星级构成），无官方视频的角色不计入均值。武器类型与角色定位相关，人均热度差异可能由「该武器承载的输出/辅助角色结构」导致，属于结构性差异而非武器本身效应。

视频播放量与收藏数的相关性 相关分析

角色级双变量散点图与 Pearson 相关系数。方法：对拥有官方视频实测数据的 n 名角色计算播放量（万）与收藏数（千）的线性相关系数 r，并按 Cohen 阈值标注强度（|r|≥0.7 强、≥0.4 中等、≥0.2 弱）。相关不等于因果：两者可能同受角色人气、版本档期等第三因素驱动。

曲目评论长尾与高异常值识别 Tukey 分布诊断

以有实测网易云评论数的去重曲目为样本，计算中位数、Q1/Q3 与 IQR，并将评论数高于 Tukey 上界 Q3 + 1.5×IQR 的曲目称为「评论高异常值」或「头部评论曲目」。这只是当前样本内的统计标记，不等于「现象级」「出圈」或因果判断；《神女劈观》另作人工背景案例展示，不由该规则自动生成传播结论。
